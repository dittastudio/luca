## Project

LUCA is a Nuxt 4 marketing website for a restaurant, driven entirely by Storyblok CMS content and deployed to Netlify.

## Commands

- `npm run dev` — pulls latest Storyblok components/types (`sb:components` + `sb:types`) then starts `nuxt dev --host`
- `npm run sb:login` / `npm run sb:logout` — Storyblok CLI authentication
- `npm run sb:components` — pull component schemas from Storyblok space `285210` into `.storyblok/`
- `npm run sb:types` — generate strict TS types from that space into `.storyblok/types/285210/`
- `npm run build` / `npm run generate` / `npm run preview` — standard Nuxt build/prerender/preview
- `npm run lint` / `npm run lint:fix` — ESLint (flat config)
- `npm run dev:ssl` — local SSL proxy, forwards `3010` → `3000` using the committed `localhost.pem` / `localhost-key.pem`
- `npm run nuke` — deletes `.output`, `dist`, `.nuxt`, `node_modules`, `package-lock.json`

There is no test runner configured in this repo.

Required `.env` vars (see README.md): `NUXT_STORYBLOK_TOKEN`, `NUXT_STORYBLOK_VERSION`, `NUXT_MAILCHIMP_API_KEY`, `NUXT_MAILCHIMP_LIST_ID`, `NUXT_MAILCHIMP_SERVER`.

## Architecture

- Nuxt 4 with `future.compatibilityVersion: 4`, app source under `app/` (the Nuxt 4 `srcDir` convention). SSR enabled, TypeScript strict, Tailwind v4 via the Vite plugin.
- **Storyblok is the source of truth for all content.** The `@storyblok/nuxt` module is configured in `nuxt.config.ts`. Component schemas and generated TS types live in `.storyblok/` (space id `285210`) and are regenerated by `sb:components` / `sb:types` — these are generated artifacts, not hand-edited, and `npm run dev` always refreshes them first. Types are imported as `@@/.storyblok/types/285210/storyblok-components` and `#storyblok-types`.
- **Story fetching**: `useStory<T>()` (`app/composables/useStory.ts`) wraps `useAsyncStoryblok`, resolves draft vs. published version from runtime config, supports Storyblok release previews via the `_storyblok_release` query param, and throws a Nuxt error (404) on fetch failure. Used for both routed pages (`app/pages/[...slug].vue`) and the global `/settings` story loaded once in `app/app.vue` (nav, footer, cover message, etc.).
- **Component layout** under `app/components/`:
  - `app/` — global chrome: `Header`, `Footer`, `Layout`, `Cover`/`CoverLogo` (splash screen), `Modal`, `Theme`, `NewsletterForm`
  - `block/` — one component per Storyblok content-type "blok" (`Card`, `CardEditorial`, `Carousel`, `Gallery`, `Media`, `Menus`, `Player`, `Split`, `Text`, `TextColumns`, `Button`), dynamically resolved by `block/Components.vue`
  - `storyblok/` — thin wrappers around Storyblok primitives (rich text, links)
  - `card/`, `media/`, `ui/`, `appearance/`, `form/`, `tool/` — presentational/reusable building blocks
- **Storyblok helpers** in `app/utils/storyblok.ts` (Nuxt auto-imports everything in `app/utils/**` as globals, not composables): `storyblokImage`/`storyblokImageUrlUpdate` build/transform asset URLs (and rewrite `a.storyblok.com` → `a2.storyblok.com`), `storyblokAssetType` classifies filenames, `storyblokSlug` normalizes routes (`/` → `/home`), `determineHref` resolves a Storyblok multilink (story/email/other) to a usable `href`.
- `app/utils/maps.ts`, `helpers.ts`, `screens.ts` hold Tailwind grid-class lookup tables, generic helpers (aspect ratio math, array chunking, delay helpers), and responsive breakpoint utilities backing `useAtMedia`.
- Custom global types live under the `Luca` namespace in `types/app.d.ts` (e.g. `Luca.ImageTransformOptions`, `Luca.TAspectRatios`) and are used unqualified across components/utils.
- `server/api/` (Nitro): `sitemap.ts` builds the sitemap from Storyblok links for `@nuxtjs/sitemap`; `oembed.post.ts` proxies oEmbed lookups for SoundCloud/Mixcloud/Vimeo/YouTube and rewrites the returned iframe `src` with extra player params; `mailchimp.ts` handles newsletter signup with zod validation and an "already subscribed" branch.
- Images go through `@nuxt/image` with a custom Storyblok provider (base URL `a2.storyblok.com`); use the manual transform helpers in `app/utils/storyblok.ts` for cases outside `@nuxt/image`.
- ESLint (`eslint.config.mjs`) layers `@antfu/eslint-config` on top of the Nuxt-generated config, with repo overrides: one attribute per line in templates, a blank line required between template tags, kebab-case custom event names. Prettier is present as a dependency but not wired into an npm script — don't assume a `format` command exists.
